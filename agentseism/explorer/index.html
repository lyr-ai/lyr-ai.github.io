What the average hides

An agent is stochastic: run it twice and some tasks come out differently. Each square below is one run. Pick a pull request and play it.

What this is. These are the three seism demo scenarios. Every run's outcome is written out in the scenario, not drawn at random, and every number and verdict on this page comes from AgentSeism's own decision engine. It shows how the check reasons. It is not evidence that the check works. For that, see the pre-registered real-agent study and the two public example PRs.

Projects

  • AgentSeism

    Measuring when execution variation becomes consequential, and testing whether agents can be steered before failure. Built around state-level instrumentation, replay, fork, and controlled intervention.

  • ReliAgent Bench

    A reproducible reliability benchmark for memory-enabled agents — the harness whose failures drove the memory work.

  • TypedMem

    Schema-aware typed memory for AI agents — what an agent carries between steps, and what that does to its behavior.
